# Рабочие таблицы

Второй проект в этом окружении — учёт, зарплата, документы и отчёты в Google Sheets/Docs.
**Кода здесь нет и не будет**: вся работа идёт через скиллы плагина `redstar`
(лежит в `claude-config/redstar/skills/`) и доступ по сервисному аккаунту
(`gsheets.js`) — см. [[google-only-via-service-account]] в памяти Claude.

Этот файл — не инструкция, а лёгкий указатель, что вообще существует, чтобы список
таблиц и их назначение не были известны только Claude по памяти. Точные ID таблиц,
правила сопоставления и контрольные суммы — в памяти Claude (`~/.claude/.../memory/`)
и внутри самих скиллов; здесь их сознательно не дублирую.
