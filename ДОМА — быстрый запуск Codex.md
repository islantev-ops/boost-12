# Дома — актуальный Codex

1. В существующей домашней копии проекта получить обновление: `git pull --ff-only`. Если настроен утренний автопулл Claude, он может сделать это при входе в Windows — проверить результат.
2. Дважды нажать **ОБНОВИТЬ CODEX.cmd** в корне обновлённого проекта. После завершения перезапустить Codex и открыть `D:\GPT Codex Redstar Dom`.

Установщик сам создаёт новую папку, если её нет; обновляет проект и Codex-config; устанавливает зависимости и Redstar; подключает инструкции и пути библиотек. Создаёт автопулл при входе в Windows и автокоммит/автопуш в 09:30, 10:00, 17:00, 17:30, 18:00, 19:45 и 23:00 по местному времени компьютера. На обеих машинах предполагается Москва. Старые задачи синхронизации Claude отключаются.

Нужны Codex, Git, Node.js/npm и доступ к приватным GitHub-репозиториям. При незакоммиченных правках или расхождении веток установщик остановится и сохранит местные изменения. Текст ошибки передать Codex.

Существующие домашние ключи остаются в `%USERPROFILE%\.gcreds` и `.aspro`. В Git они не передаются. Установщик проверяет наличие файлов; действительность доступов проверяется отдельным запросом к сервисам. Метрику и Вебмастер ранее отложили.

Рабочая память, инструкции и журнал приезжают в Codex-config. Старые чаты, архивы и локальные результаты через Git автоматически не переносятся: они сохранены на рабочем компьютере внутри `D:\GPT Codex Redstar\рабочее`.

Для повторного обновления запускать тот же **ОБНОВИТЬ CODEX.cmd**. Старый Claude bootstrap.ps1 для настройки Codex не запускать.
