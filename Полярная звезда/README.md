## Развернуть у себя

```bash
git clone <адрес репозитория> "Claude redstar"
cd "Claude redstar/Полярная звезда/product-mvp"
npm install
npm run dev            # http://localhost:3000
```

Базы локально нет — раньше PostgreSQL жил на VPS и слушал только localhost, сервера
больше нет вовсе. Интерфейс это переживает и честно пишет «База недоступна» — вёрстку
и логику смотреть можно.

Проверить любой сайт без базы и интерфейса:

```bash
npm run check-site https://example.ru
```

Полностью, с базой — см. [README приложения](product-mvp/README.md): там установка
PostgreSQL, `schema.sql`, `seed.sql` и (устаревший) раздел про деплой.

## Правило, которое важнее кода

Законы и суммы штрафов берутся **только из КонсультантПлюс**, каждая норма — со
ссылкой с якорем на конкретную часть статьи. Выдумывать нормы нельзя. Всё лежит
в одном месте: [product-mvp/src/lib/legal.ts](product-mvp/src/lib/legal.ts).

Состав проверок задан чек-листом на лендинге. Менять — сначала там, потом в коде.
