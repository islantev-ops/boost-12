# Создание задачи в Aspro с копированием в две Google-таблицы

Дата: 2026-07-21

## Задача

Пользователь присылает в чат формулировку задачи, оценку в часах и исполнителя.
Claude создаёт задачу в Aspro.Cloud и записывает её в две Google-таблицы.

## Входной формат

```
Саша Егор Июль 21: техническое собеседование № 4 Ярош 1 час
Исполнитель Разработчик  срок начала сейчас
```

- Первая строка до указания часов — **название задачи в финальном виде**.
  Правил формулирования Claude не применяет: что прислано, то и пишет.
- `1 час` — оценка. В название не входит. Идёт в три места: Aspro и обе таблицы.
- `Исполнитель <роль>` — ответственный в Aspro. По умолчанию «Разработчик Штатный».
- `срок начала сейчас` — дата начала = текущий момент.

## Каналы доступа

**Aspro.Cloud — только через браузер (Playwright).** REST API отпадает:
на текущем тарифе портала функционал API отключён («Функционал „Программный
интерфейс (API)“ недоступен на вашем тарифе»). Проверено: запрос без ключа
возвращает `{"error":{"error_code":11,"error_msg":"api key not found"}}`,
но выдать ключ в интерфейсе нельзя.

Авторизация — разовый ручной вход в видимом окне браузера, состояние сессии
сохраняется в `%USERPROFILE%\.aspro\state.json` (вне репозитория). При
протухании сессии вход повторяется вручную. Пароль нигде не хранится.

**Google Sheets и Drive — напрямую**, модуль `boost-tools/lib/gsheets.js`,
авторизация сервисным аккаунтом (ключ в `%USERPROFILE%\.gcreds\`, вне
репозитория). Права выданы на папку файлов учёта и папку проектов, поэтому новые
файлы внутри доступны без донастройки.

Zapier, использовавшийся изначально, отключён 2026-07-22: лимит задач на тарифе
исчерпывался, `values:batchGet` возвращался повреждённым, часть вызовов
переспрашивала подтверждение вместо выполнения.

## Целевые объекты

### Aspro

Проект 68 = `SUP - ЦМИК 2.0`,
`https://redstar.aspro.cloud/_module/st/view/project/68?tab=project_tasks.board`

**Основной способ открыть форму** — подменить адрес у пункта меню «Создать
задачу» в шапке проекта, добавив `group_id` этапа, и кликнуть по нему:

```js
document.querySelector('a[data-href="/_module/task/view/edit?project_id=68"]')
  .setAttribute('data-href', '/_module/task/view/edit?group_id=919&project_id=68');
```

Затем «Создать» → пункт с новым `data-href`. Форма открывается уже со связью
`SUP - ЦМИК 2.0, Этап: Июль 2026` — проверено. Ни клики по координатам, ни диалог
«Изменить связи» не нужны.

`group_id` — это id этапа. Берётся с доски: у карточки задачи атрибут
`data-section-id` на 8 уровней выше текстового узла. Для «Июль 2026» — **919**.
При смене месяца id нужно перечитать.

Отвергнутые способы: «плюс» в строке этапа ищется только по координатам (иконка
без текста) и открывает мини-форму без поля оценки — из неё нужен ещё клик по
`button[title="Полная форма"]`. Кнопка «Создать» без `group_id` даёт форму без
этапа.

Поля формы:

| Что | Где | Значение |
|---|---|---|
| Название | Основные, `input[name=name]` | полное название из сообщения |
| Описание | Основные, `[contenteditable=true]` | дословная копия названия |
| Ответственный | Основные | «Разработчик Штатный» — **задать явно**, по умолчанию стоит «Менджер Проектов» |
| Дата начала | Основные | текущий момент |
| Оценка по времени | Дополнительно, `input[placeholder="ч м"]` | `<часы>ч` |

Поле «Этап» в форме есть — это блок **«Связанная сущность»** на вкладке
«Дополнительно». Он собран из ссылок, а не из `input`, поэтому не виден при
переборе полей ввода.

**id созданной задачи** берётся с доски: у карточки атрибут `data-item-id`
(8 уровней выше текстового узла). Ответ на сохранение id не содержит,
ссылок `a[href*="/task/view/task/"]` на доске и в списочном виде нет.

Оценка измеряется в часах. Подтверждено плейсхолдером «ч м» и задачей 7595,
где `0м 0с / 1ч 0м` соответствует оценке `1` в таблице учёта.

### Таблица учёта Ислантьева

`1IaXZJPl42xPPnBeIsXQ9jQvelr7EAY06RgeaZUxfoeU`, вкладка **«Цмик»**
(sheetId 720687444). Заголовки в строке 5, данные с шестой.

| Колонка | Содержимое |
|---|---|
| A | полное название задачи (с именами) |
| B | `https://redstar.aspro.cloud/_module/task/view/task/<id>` |
| C | оценка в часах |
| D | полное имя исполнителя |
| E | `в работе` |

Строка дописывается в конец списка (на 2026-07-21 следующая свободная — 14).

Сопоставление коротких имён из заголовка с полными:

| В заголовке | В колонке D |
|---|---|
| Миша | Миша Шабаев |
| Тони | Тони Ахтер |
| Егор | Егор Барыкин |
| Саша | Саша Ислантьев |

Список неполный — при встрече незнакомого имени спросить пользователя, не гадать.

### Таблица задач ЦМИК

`1q5FPr5ji_6lqm0Bf7sX_0GjNoLDGa2oW_lWEy7GVr1I`, вкладка по месяцу —
**«Июль 2026»** (sheetId 475899357). Одна вкладка на каждый месяц.

| Колонка | Содержимое |
|---|---|
| A | порядковый номер — **уже проставлен, не трогать** |
| B | название **без имён**: всё до названия месяца отрезано |
| E | оценка в часах |
| F | `в работе` |
| G | ТЗ — не участвует, не трогать |

Правило обрезки: `Саша Егор Июль 21: …` → `Июль 21: …`, то есть всё до первого
названия месяца отбрасывается.

Строка пишется в **первую строку с пустым `B`** (на 2026-07-21 — строка 7), а не
в конец диапазона: номера в колонке `A` заполнены заранее до 27-й позиции.

Справа на том же листе — независимый список багфиксов (колонки `I`, `J`, `M`).
К задачам отношения не имеет, не трогать.

Старая таблица `1xnNVz9kJ9fxRr868qs1qF93afMNoEvoE` («ЦМИК таблица задач.xlsx»)
**не используется**: это Office-файл, Sheets API её не обслуживает.

## Порядок выполнения

1. Разобрать сообщение, показать пользователю итог: название, обрезанное
   название, ответственный, исполнитель для учёта, оценка, этап. Дождаться «да».
2. Создать задачу в Aspro, забрать id.
3. Записать строку в таблицу учёта.
4. Записать строку в таблицу ЦМИК.
5. Отчитаться по шагам 2–4 **раздельно**.

Порядок обусловлен необратимостью шага 2: если запись в таблицы упадёт после
создания задачи, задача останется в трекере, и об этом надо сказать прямо, а не
отрапортовать «готово».

## Первый прогон, 2026-07-21

Задача `Саша Егор Июль 21: техническое собеседование № 4 Ярош`, id **7678**.
Создана, этап «Июль 2026» проставился, оценка `1ч 0м` записалась, описание
продублировано. Строки записаны: `'Цмик'!A14:E14` и `'Июль 2026'!B7`, `E7:F7`.

Две ошибки исполнения, обе исправлены вручную после проверки:

- ответственный остался «Менджер Проектов» — поле не заполнялось скриптом вообще;
- дата начала не проставлялась — поле было потеряно при сборке скрипта.

Вывод: после сохранения **обязательно перечитывать страницу задачи** и сверять
все поля, а не полагаться на отсутствие ошибок при заполнении.

## Что не проверено

- Время в поле «Дата начала». Ввод текстом в поле не срабатывает — дата
  выставляется кликом по календарю, при этом записывается только число без
  времени.
- Полный список пользователей Aspro: в выпадашке «Ответственный» виден только
  первый экран — «Анна Супер Админ», «Артём Коротков», «Менджер Проектов»,
  «Разработчик Штатный». Полного перебора не делалось.

## Отложено

Правила формулирования названий; логика «одна работа на двоих = две задачи»
(в существующих данных встречается, но в текущий сценарий не входит);
выбор исполнителя, отличного от «Разработчик Штатный».
